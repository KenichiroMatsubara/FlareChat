# Issue tracker: GitHub

Issues and PRDs for this repository always live in GitHub Issues at
`KenichiroMatsubara/FlareChat`. Use the `gh` CLI for all operations and infer
the repository from the configured `origin` remote.

Do not ask which issue tracker to use. GitHub Issues is the only tracker for
this repository unless this file is explicitly changed.

## Conventions

- Create an issue with `gh issue create`.
- Read an issue and its discussion with `gh issue view <number> --comments`.
- List and filter issues with `gh issue list` and JSON output.
- Apply or remove labels with `gh issue edit`.
- Close an issue with `gh issue close`.

When a skill says to publish an issue or PRD, create a GitHub issue in this
repository.
