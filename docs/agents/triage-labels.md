# Triage labels

The engineering skills use these mappings for triage roles.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for unattended implementation |
| `ready-for-human` | `ready-for-human` | Requires fully manual human work |
| `wontfix` | `wontfix` | Will not be actioned |

Use `ready-for-agent` for AFK implementation issues and `ready-for-human` only
for work that must be completed entirely by a person. Do not create mixed HITL
implementation issues.
