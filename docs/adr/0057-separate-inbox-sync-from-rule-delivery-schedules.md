# Separate inbox sync from rule delivery schedules

The Automation Inbox performs incremental Gmail synchronization every thirty minutes, independent of Automation Rule Run Schedules. This bounds recurring D1 reads and Gmail API traffic while the manual “check now” action preserves an immediate path when needed. Matching rules share extracted Event Candidates and Scheduled Events but execute their routing and deliveries once at their own due times; recipient and LINE destination identities deduplicate across runs so different rule schedules can coexist without duplicate invitations or notifications.
