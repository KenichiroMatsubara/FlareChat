# Classify events into organization categories

Organizations define a closed set of optional Event Categories such as regular meetings, board meetings, or service activities. AI selects from that set rather than inventing labels, and each category may supply default recipient lists, LINE destinations, Registration Deadline behavior, and notification templates that Routing Policies refine. If no category fits, the Event Candidate remains uncategorized and produces an Automation Warning rather than being forced into a fallback category.
